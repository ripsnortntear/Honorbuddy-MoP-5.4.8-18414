1. Put both folders in your Honorbuddy Bots folder

2. Restart Honrobuddy

3. Select ProfessionBuddy as the botbase

4. Press the Bot Config button (it might take a minute to load)

5. Select Easy Tokens.xml from the left panel

6. Select the amount of stacks of fish you want the bot to catch before it turns them in for tokens. (if you change the default value whcih is 100 you need to restart Honorbuddy for settings to take place)

7. If you changed the default stack value you have to repeat steps 2-5 then press start!

Make sure your in Valley of the Four Winds!
